# StudySpace v1.0

Telegram Mini App — учебное рабочее пространство для студентов колледжей и техникумов:
расписание, задания, предметы, конспекты, файлы и обмен материалами (личные / групповые / общая библиотека).

Проект полностью бесплатный: без платных API, подписок и обязательной привязки карты.

## Стек

- Frontend: React + TypeScript + Vite + Tailwind CSS 4, официальный `telegram-web-app.js`
- Backend: Cloudflare Workers + Hono
- База данных: Cloudflare D1 (SQLite), в базе только метаданные
- Файлы: приватный Telegram-канал платформы через Bot API (без карты; лимит ~20 МБ на файл)
- Авторизация: Telegram Mini Apps initData с серверной проверкой подписи

## Структура

```
frontend/   — React-приложение (Mini App)
backend/    — Workers API (Hono)
database/   — миграции D1
```

## Локальный запуск (Windows PowerShell)

Требуется Node.js 20.19+ и Git.

```powershell
# Терминал 1 — backend (API на http://localhost:8787)
cd C:\studiapp\backend
npm install
npx wrangler d1 migrations apply studyspace --local
npm run dev

# Терминал 2 — frontend (интерфейс на http://localhost:5173)
cd C:\studiapp\frontend
npm install
npm run dev
```

Вне Telegram приложение работает в режиме разработки: данные Telegram недоступны,
авторизованные функции появятся после подключения бота (Этап 2).

Проверка API: `curl http://localhost:8787/api/health` → `{"status":"ok","database":true}`.

## Бесплатные лимиты (проверено 10.11.2026 по официальной документации)

- Workers Free: 100 000 запросов/день, 10 мс CPU/запрос; статика бесплатна и без лимита запросов
- D1 Free: 5 млн чтений строк/день, 100 тыс. записей/день, 5 ГБ
- Telegram Bot API: бесплатно; getFile скачивает файлы до 20 МБ
- Перед развёртыванием условия тарифов перепроверяются

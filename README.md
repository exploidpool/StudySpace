# StudySpace v1.0

Telegram Mini App — учебное рабочее пространство для студентов колледжей и техникумов:
расписание, задания, предметы, конспекты, файлы и обмен материалами (личные / групповые / общая библиотека).

Проект полностью бесплатный: без платных API, подписок и обязательной привязки карты.

## Стек

- Frontend: React + TypeScript + Vite + Tailwind CSS 4, официальный `telegram-web-app.js`
- Backend: Cloudflare Workers + Hono
- База данных: Cloudflare D1 (SQLite), в базе только метаданные
- Файлы: приватный Telegram-канал платформы через Bot API (без карты; лимит ~20 МБ на файл)
- Авторизация: Telegram Mini Apps initData с серверной проверкой подписи

## Структура

```
frontend/   — React-приложение (Mini App)
backend/    — Workers API (Hono)
database/   — миграции D1
```

## Локальный запуск (Windows PowerShell)

Требуется Node.js 20.19+ и Git.

```powershell
# Терминал 1 — backend (API на http://localhost:8787)
cd C:\Users\Administrator\Documents\Codex\my-proj\StudySpace\backend
npm install
npx wrangler d1 migrations apply studyspace --local
npm run dev

# Терминал 2 — frontend (интерфейс на http://localhost:5173)
cd C:\Users\Administrator\Documents\Codex\my-proj\StudySpace\frontend
npm install
npm run dev
```

Вне Telegram приложение работает в режиме разработки: данные Telegram недоступны,
авторизованные функции доступны при открытии через Telegram-бота.

Проверка API: `curl http://localhost:8787/api/health` → `{"status":"ok","database":true}`.

## Бесплатные лимиты (проверено 10.11.2026 по официальной документации)

- Workers Free: 100 000 запросов/день, 10 мс CPU/запрос; статика бесплатна и без лимита запросов
- D1 Free: 5 млн чтений строк/день, 100 тыс. записей/день, 5 ГБ
- Telegram Bot API: бесплатно; getFile скачивает файлы до 20 МБ
- Перед развёртыванием условия тарифов перепроверяются

## Пилот расписания ИС-942

Добавлены серверные версии расписания (черновик → публикация → архив), просмотр сегодня и недели, административный редактор с импортом PNG/JPG. Студенты видят только опубликованные занятия. Расписание привязано к понедельнику конкретной недели; «сегодня» определяется по `Asia/Novosibirsk`.

После установки зависимостей примените локальные миграции командой `npm run db:migrate:local` из `backend`. Первому администратору владелец вручную назначает `role = 'admin'` в таблице `users` своей D1; публичного повышения роли нет. Удалённая база и публикация приложения в рамках разработки не изменяются.

Администратор открывает «Расписание», выбирает неделю и изображение, проверяет область ИС-942, исправляет строки, сохраняет черновик и отдельно подтверждает публикацию. Для исправления опубликованной недели создаётся новый черновик. Подгруппы показываются отдельно, кабинет сохраняется точно как указан. Исходное фото не отправляется на сервер; OCR не гарантирует распознавание рукописных исправлений.

Описание предоставленных примеров: [docs/schedule-photo-fixtures.md](docs/schedule-photo-fixtures.md). Актуальные ограничения установки и проверки фиксируются в отчёте о реализации; наличие исходного кода не означает завершённую приёмку на Telegram Mobile/Desktop.

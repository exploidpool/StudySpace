# StudySpace v1.0

Telegram Mini App — учебное рабочее пространство для студентов колледжей и техникумов:
расписание, задания, предметы, конспекты, файлы и обмен материалами (личные / групповые / общая библиотека).

Проект полностью бесплатный: без платных API, подписок и обязательной привязки карты.

## Стек

- Frontend: React + TypeScript + Vite + Tailwind CSS 4, официальный `telegram-web-app.js`
- Backend: Cloudflare Workers + Hono
- База данных: Cloudflare D1 (SQLite), в базе только метаданные
- Файлы: приватный Telegram-канал платформы через Bot API (без карты; лимит ~20 МБ на файл)
- Авторизация: Telegram Mini Apps initData с серверной проверкой подписи

## Структура

```
frontend/   — React-приложение (Mini App)
backend/    — Workers API (Hono)
database/   — миграции D1
```

Результат на 10.11.2026: `verify-initdata` 7/7, `verify-study` 16/16, typecheck и сборка без ошибок.
UI проверен в браузере с подписанным initData (golden path): создание предмета, конспекта с
автосохранением и поиском, занятия (день/неделя), задания с дедлайном и переключением статуса,
статистика на главной и в профиле; консоль без ошибок. Данные подтверждены в локальной D1.

Особенности:
- Поиск конспектов использует SQLite `LIKE` — для кириллицы регистрозависим (LOWER в SQLite
  не работает для не-ASCII). Запрос «производных» найдёт текст, «ПРОИЗВОДНЫХ» — нет.
- Дни недели хранятся как 0=Пн…6=Вс, время занятий — локальное « wall » HH:MM без даты.
- Срок задания (`due_at`) хранится в UTC ISO и конвертируется в локальное время на клиенте.
- Удаление предмета не удаляет связанные занятия/задания/конспекты, а отвязывает их (`subject_id=NULL`).

## Этап 4 — файлы и материалы (реализовано и проверено)

Хранилище — приватный Telegram-канал или группа через Bot API (без карты, в отличие от R2). Сами файлы
лежат в чате-хранилище, в D1 только метаданные и `file_id`. Скачивание проксируется backend с проверкой
прав — прямой URL с токеном бота клиенту не выдаётся. Личные файлы доступны только владельцу; общая
библиотека — всем; избранное, жалобы и модерация админом реализованы.

Подключение хранилища:
1. Создайте приватный канал или группу в Telegram.
2. Добавьте бота администратором с правом публикации сообщений.
3. Узнайте id чата (бот получит `my_chat_member`-обновление) и пропишите `TELEGRAM_STORAGE_CHANNEL_ID` в `.dev.vars`.
4. Перезапустите `npm run dev` в backend.

Проверка:

```powershell
cd C:\Users\bonda\Documents\Qoder\2026-11-10\3ebaa3c5\StudySpace\backend
node scripts/verify-materials.mjs
```

Тест сам подписывает initData для владельца/читателя/админа. Без настроенного канала файловые
проверки честно пропускаются (SKIP), выполняются только базовые проверки доступа. С каналом —
полный цикл: загрузка, проверка формата/магических байтов, изоляция, скачивание байт-в-байт,
публикация, поиск/фильтры, избранное, жалобы, модерация (скрытие/возврат), IDOR, каскадное удаление.

Ограничения и особенности:
- Форматы: PDF, DOCX, PPTX, TXT, PNG, JPG/JPEG. Проверка расширения, MIME и магических байтов.
- Лимит 20 МБ на файл (ограничение getFile) и 100 файлов на пользователя.
- Публикация в библиотеку — явное действие (`visibility=public`); сменить приватность иначе нельзя.
- Удаление файла каскадно удаляет его публикации, избранное и жалобы.
- Статус на 10.11.2026: полная проверка 21/21 (0 failed, 0 skipped) с реальной группой-хранилищем;
  typecheck и сборка без ошибок; UI проверен в браузере (загрузка 201 → публикация 201 с уведомлением
  о доступе → библиотека → избранное → скачивание 200 application/pdf). Результаты не выдуманы.

## Бесплатные лимиты (проверено 10.11.2026 по официальной документации)

- Workers Free: 100 000 запросов/день, 10 мс CPU/запрос; статика бесплатна и без лимита запросов
- D1 Free: 5 млн чтений строк/день, 100 тыс. записей/день, 5 ГБ
- Telegram Bot API: бесплатно; getFile скачивает файлы до 20 МБ
- Перед развёртыванием условия тарифов перепроверяются
